# Deal Data Summarizer

A Python script that reads a CRM-style deal export (CSV) and prints a pipeline summary: total and average deal size, open pipeline, win rate, and breakdowns by stage, rep and vendor.

## Why I built it
Week 1 of my solutions engineering portfolio: practice working with structured deal data before connecting to a live CRM API.

## How to run
Requires Python 3 (no extra packages).

```bash
python3 summarize.py
```
